# Motor Controller | PulsarEV

Motor driver hardware and embedded motor-control development.

## Project files

- `hardware/MotorSurucu.PrjPcb` — Altium project
- `hardware/MotorSurucu.SchDoc` — blank schematic
- `hardware/MotorSurucu.PcbDoc` — blank PCB with provisional design rules
- `hardware/MotorSurucu.SchLib` and `hardware/MotorSurucu.PcbLib` — blank libraries
- `embedded/` — embedded firmware workspace
- `docs/` — project documents

**Getting started:** Clone the repository, then open the `.PrjPcb` file once the native Altium source has been imported into `hardware/`.

**Status:** Template scaffold; PCB rules require review for this subsystem. No completed design or electrical validation is claimed.
