# New engineer onboarding — Motor Controller

1. Confirm organizational repository access and read [the root README](../../README.md).
2. Review the [requirements](../requirements/system-requirements.md) and [architecture](../architecture/system-overview.md).
3. Select your workstream: [hardware](../../hardware/README.md) or [embedded](../../embedded/README.md).
4. Identify the latest native design files and their source-controlled dependencies.
5. Read the [interface control document](../interfaces/interface-control.md).
6. Choose an issue, create a topic branch and follow [CONTRIBUTING](../../CONTRIBUTING.md).
7. Submit a PR with explicit build/test evidence or explain why validation was blocked.

For optional local EDA assistance, follow the [EDA Agent setup](../eda-agent-setup.md). The MCP server is installed per developer and can modify active design files; review its safety guidance before connecting it.

## Important

Tool versions, hardware revisions, firmware dependencies, and physical lab access must be confirmed with the team. Empty directories and TBD entries mean work remains; do not invent solutions.
