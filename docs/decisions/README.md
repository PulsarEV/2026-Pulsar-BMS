# Architecture Decision Records (ADR)

Create one Markdown document per meaningful decision, e.g. `0001-design-boundary.md`.

## ADR template

- **Status:** Proposed / Accepted / Superseded
- **Context:** What engineering problem are we solving?
- **Options:** Alternatives with constraints and trade-offs
- **Decision:** The selected approach (only after approval)
- **Consequences:** Benefits, new risks and verification needs
- **Evidence:** Design documents, calculations, issue/PR links

Do not create a fictional decision history.
